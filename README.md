# IntervalAnalysis
Лабораторная работа №1
По интервальному анализу
3 сентября 2026 г.
Задание
Даны интервальные системы линейных алгебраических уравнений
Ax = b. (1)
1. Прямоугольная матрица
Рассмотрим интервальную матрицу A1 ∈ IR3×2
с матрицей центров
mid A1 =
  0.95 1.00
( 1.05 1.00 )
  1.10 1.00           (2)
Матрица радиусов имеет один из следующих видов (томография/регрессия):
rad A1 = δ *
  1.00 1.00
( 1.00 1.00 )
  1.00 1.00      (3)
или
rad A1 = δ *
  1.00 0.00
( 1.00 0.00 )
  1.00 0.00      , δ ≥ 0. (4)
Для матрицы A1:
1. Найти диапазон значений параметра δ, при которых интервальная матрица A1 содержит точечную матрицу неполного столбцового ранга (становится особенной).
2. Для найденного минимального значения δ построить точечную матрицу A′1 ∈ A1, для
которой det A′1 = 0.
3. Проверить принадлежность найденной матрицы A′1 интервальной матрице A1 и убедиться в её особенности.

2. Квадратная матрица
Рассмотрим интервальную матрицу A2 ∈ IR3×3
с матрицей центров
mid A2 =
  1.10 0.90 1.10
( 1.40 1.00 0.80 )
  0.80 1.40 1.20,    (5)
и матрицей радиусов
rad A2 = δ *
  1.00 1.00 1.00
( 1.00 1.00 1.00 )
  1.00 1.00 1.00,       δ ≥ 0. (6)
Для матрицы A2:
1. Найти диапазон значений параметра δ, при которых интервальная матрица A2 становится особенной, т. е. содержит хотя бы одну особенную точечную матрицу.
2. Для найденного минимального значения δ построить точечную матрицу A′2 ∈ A2, для которой det A′2 = 0.
3. Проверить принадлежность найденной матрицы A′2 интервальной матрице A2 и убедиться в её особенности.
3. Обсуждение результатов
Обсудить полученные результаты для прямоугольной и квадратной интервальных матриц
для случаев линейной регрессии и малоракурсной томографии.
