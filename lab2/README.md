# IntervalAnalysis

Лабораторная работа №2 По интервальному анализу

Вариант 4

## Цель работы

Исследование и сравнение точности различных методов интервального оценивания областей значений функций одной и нескольких переменных. Изучение влияния формы функционального выражения, положения центра и ширины интервального бруса на качество получаемых внешних оценок.

## Задача

В работе рассматриваются две функции одной переменной f1(x), f2(x) и одна функция двух переменных f3(x, y).

### 1. Функции одной переменной

Для каждой из функций f1(x) и f2(x) на интервале X = [a, b] необходимо выполнить следующие пункты.

**A.** Аналитически или численно найти точную область значений:

ran(f, X) = {f(x) | x ∈ X} = [ min x∈X f(x), max x∈X f(x) ]

Построить график функции на заданном интервале.

**B.** Вычислить интервальные оценки области значений, используя:

*   **B.1.** естественное интервальное расширение исходного выражения функции;
*   **B.2.** естественное интервальное расширение эквивалентного выражения функции, полученного с помощью схемы Горнера или другого алгебраического преобразования;
*   **B.3.** дифференциальную центрированную форму

    F_mv(X, c) = f(c) + f'(X)(X - c)

    с центром в различных точках интервала;

*   **B.4.** наклонную центрированную форму

    F_sl(X, c) = f(c) + f_угол(X, c)(X - c)

    с центром в различных точках интервала;

*   **B.5.** бицентрированную среднезначную форму.

**C.** Для каждой полученной интервальной оценки F(X) вычислить расстояние по Хаусдорфу

dist(F(X), ran(f, X))

до точной области значений.

Проанализировать точность естественного интервального расширения:

*   **C.1.** найти аналитически или численно константу Липшица L функции f на интервале X и обосновать её выбор;
*   **C.2.** получить теоретическую оценку

    rad F(X) ≤ L * rad X

*   **C.3.** сравнить полуширину полученной интервальной оценки rad F(X) с теоретической оценкой.

**D.** Сравнить полученные результаты. Объяснить наблюдаемую точность или переоценку каждого метода и влияние выбора центра и формы аналитического выражения функции.

### 2. Функция двух переменных

Для индивидуальной функции f3(x, y) на прямоугольном брусе X = X1 × X2 необходимо выполнить следующие пункты.

**E.1.** Построить график поверхности z = f3(x, y) и линии уровня функции на заданном брусе X.

**E.2.** Найти аналитически или численно область значений

ran(f3, X) = [ min (x,y)∈X f3(x,y), max (x,y)∈X f3(x,y) ]

**E.3.** Вычислить естественное интервальное расширение исходного выражения функции.

**E.4.** Если возможно, получить алгебраически эквивалентное выражение функции и вычислить его естественное интервальное расширение. Сравнить полученные интервальные оценки.

**E.5.** Вычислить дифференциальную центрированную форму

F_mv(X, c) = f3(c) + (∂f3/∂x)(X)(X1 - c1) + (∂f3/∂y)(X)(X2 - c2)

где c = (c1, c2) ∈ X. Провести вычисления не менее чем для двух различных центров, один из которых должен совпадать с серединой бруса c = mid X.

**E.6.** Построить бицентрированную среднезначную форму согласно теореме Бауманна и сравнить её с естественным интервальным расширением и дифференциальной центрированной формой.

**E.7.** Исследовать влияние дробления исходного бруса на качество интервальной оценки. Разбить брус X пополам:
(a) по координате x;
(b) по координате y.

Для каждого разбиения вычислить естественные интервальные расширения на двух полученных подбрусах.

Для интервалов A = [a_нижн, a_верх], B = [b_нижн, b_верх] интервальную оболочку определить как

□(A ∪ B) = [min(a_нижн, b_нижн), max(a_верх, b_верх)]

Сравнить полученные оболочки с естественным интервальным расширением функции на исходном брусе.

**E.8.** Для функции f3 получить покоординатную липшицевскую оценку. Найти величины

L1 ≥ sup (x,y)∈X |∂f3/∂x|, L2 ≥ sup (x,y)∈X |∂f3/∂y|

Проверить оценку

rad F3(X) ≤ L1 * rad X1 + L2 * rad X2

**E.9.** Для всех полученных внешних интервальных оценок вычислить расстояние до найденной области значений ran(f3, X).

Сравнить результаты и сделать выводы о влиянии:
*   зависимости между переменными;
*   формы функционального выражения;
*   выбора центра;
*   дробления бруса
на точность интервального оценивания.

f1(x) = x^3 - 3x^2 + 2, X = [0, 3]
